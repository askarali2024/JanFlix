Drop your movie files in this folder (or configure MEDIA_DIRS in .env to
point anywhere else — JanFlix scans folders in place and never copies).

Supported: .mp4 .mkv .webm .mov .avi .m4v   (files >= 50 MB)

Example:
  The.Odyssey.2026.1080p.WEBRip.x264.mp4
  The.Odyssey.2026.1080p.WEBRip.x264.srt    <- optional subtitles

Then open JanFlix and hit "Scan Library".
